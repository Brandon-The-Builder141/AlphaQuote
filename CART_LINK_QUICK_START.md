# 🔗 Cart Link Import - Quick Start Guide

## What is Cart Link Import?

Import materials from **any retailer cart link** in just 3 clicks!  
Works with Home Depot, Lowe's, Amazon, Menards, Ace Hardware, and more.

---

## 🚀 Quick Start (30 seconds)

### **Method 1: Paste Cart Link** ⭐ Recommended

```
1. Get your cart link from retailer
   (Look for "Share Cart" or copy the URL)

2. In AlphaQuote, click "Import Cart"
   → Select "Paste Cart Link" tab

3. Paste your cart URL
   Example: https://homedepot.com/mycart/share/ABC123

4. Click "Open Cart"
   → Cart page opens in new tab
   → AlphaQuote shows specific copy instructions

5. On cart page, select all (Ctrl+A) and copy (Ctrl+C)

6. Return to AlphaQuote, paste in Step 3
   → Click "Parse Cart Text"

7. Review items → Click "Import"
   ✅ Done! Items added to your estimate
```

**Time: ~30 seconds**

---

### **Method 2: Use Bookmarklet** 🔥 Power Users

**One-Time Setup:**
```
1. Click "Import Cart" in AlphaQuote
2. Click "Show Advanced: One-Click Bookmarklet"
3. Click "Copy Code"
4. Create new bookmark in browser
5. Name it "AlphaQuote Extract"
6. Paste the code as the URL
```

**Every Time After:**
```
1. Go to any retailer cart page
2. Click your "AlphaQuote Extract" bookmark
3. Data auto-copied to clipboard!
4. Paste in AlphaQuote Step 3
5. Import!
```

**Time: ~15 seconds**

## 💡 Pro Tips

### Get Your Cart Link:
- **Home Depot:** Cart page → Click "Share Cart" → Copy link
- **Lowe's:** Cart page → URL is already shareable
- **Amazon:** Cart page → Copy URL from address bar
- **Email:** Many retailers email cart links → Just paste that!

### If Link Doesn't Work:
- No problem! Just use "Browse Suppliers" tab instead
- Or manually navigate to cart page
- Then copy/paste cart text as usual

### Bookmarklet Troubleshooting:
- Make sure you're on the actual cart page
- Some sites block JavaScript - use manual copy if needed
- Works best on desktop browsers

## 🎯 What Gets Imported?

Each cart item becomes a work item in your estimate:

| Cart Data | → | Estimate Field |
|-----------|---|----------------|
| Item Name | → | Room Name & Material |
| Quantity | → | Square Footage |
| Unit Price | → | Material Cost/sqft |
| Total Price | → | Calculated total |

You can edit everything after import!

## ❓ Common Questions

**Q: Do all retailers support cart links?**  
A: Most do! If not, you can still copy/paste cart text.

**Q: Is my data sent anywhere?**  
A: No! Everything happens locally in your browser.

**Q: Can I import multiple carts?**  
A: Yes! Import first cart, then repeat for second cart. Items will be added.

**Q: What if parsing fails?**  
A: Try simplifying the text format (Name, Qty, Price) and parse again.

**Q: Does the bookmarklet work on mobile?**  
A: Best on desktop. Mobile browsers have limited bookmark support.
