## 📋 Step-by-Step Visual Guide

### **Step 1: Access Vendors**
1. Look at the **left sidebar** (dark blue/slate)
2. Find **"Vendors"** in the navigation menu
3. Click on **"Vendors"**

### **Step 2: Create New Vendor with Website**
Once on the Vendors page, you'll see:

```
┌─────────────────────────────────────────┐
│ 🏪 Vendor Management                    │
│ Manage your local vendors and suppliers │
├─────────────────────────────────────────┤
│                                         │
│ [+ Add New Vendor]  ← Click this!      │
│                                         │
└─────────────────────────────────────────┘
```

### **Step 3: Fill in the Form**
You'll see a form with these fields:

```
┌─────────────────────────────────────────┐
│ Create New Vendor                       │
├─────────────────────────────────────────┤
│                                         │
│ 🏢 Vendor Name *                        │
│ [e.g., Home Depot, Local Hardware]     │
│                                         │
│ 👤 Contact Information                  │
│ [Phone, email, or contact person]      │
│                                         │
│ 🌐 Website URL  ← NEW FIELD!           │
│ [https://www.example.com]               │
│ Optional: Vendor's website for quick   │
│ access and cart imports                │

│ 📝 Notes                                │
│ [Any additional information]           │
│                                         │
│ [Cancel]              [Create Vendor]  │

```

### **Step 4: View Vendors with Websites**
Back on the Vendors page, you'll see vendor cards like:

## 🎯 Key UI Elements to Look For

### **In the Vendors Section:**

| Element | What to Look For |
|---------|------------------|
| **Add Button** | Big teal/cyan button with "+ Add New Vendor" |
| **Vendor Cards** | Dark cards with vendor name, contact, website |
| **Website Link** | 🌐 Globe icon + clickable text + 🔗 arrow |
| **Edit Button** | Small ✏️ pencil icon in top-right of card |
| **Delete Button** | Small 🗑️ trash icon in top-right of card |

### **In the Create/Edit Form:**

| Field | Icon | Required | Example |
|-------|------|----------|---------|
| Vendor Name | 🏢 | Yes* | Home Depot |
| Contact Info | 👤 | No | 800-HOME-DEPOT |
| Website URL | 🌐 | No | https://www.homedepot.com |
| Notes | 📝 | No | Local store #1234 |

## 💡 Quick Tips

### **Adding Multiple Vendors:**
```
Common vendors to add:
✅ Home Depot → https://www.homedepot.com
✅ Lowe's → https://www.lowes.com
✅ Menards → https://www.menards.com
✅ Ace Hardware → https://www.acehardware.com
✅ Your local supplier → their website
```

### **Using the Website Links:**
1. **Click the website link** on any vendor card
2. **New tab opens** with vendor's website
3. **Build your cart** on their site
4. **Copy cart text** (Ctrl+A, Ctrl+C or right-click → Select All → Copy)
5. **Return to AlphaQuote** tab
6. **Go to New Estimate** → Click **"Import Cart"**
7. **Paste and import!**
